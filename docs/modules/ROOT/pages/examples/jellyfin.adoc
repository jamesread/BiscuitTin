= Jellyfin

This tile starts the https://jellyfin.org/[Jellyfin] *desktop player*, not the server.
The server is a separate service; the player connects to it.
This is the fourth tile on the screenshot home screen.

== Config

The official client is https://github.com/jellyfin/jellyfin-desktop[Jellyfin Desktop], distributed on Flathub as https://flathub.org/apps/org.jellyfin.JellyfinDesktop[`org.jellyfin.JellyfinDesktop`]:

[source,shell]
----
flatpak install flathub org.jellyfin.JellyfinDesktop
----

[source,yaml]
----
entries:
  - title: Jellyfin
    subtitle: Media server
    command: [flatpak, run, org.jellyfin.JellyfinDesktop, --tv]
----

`--tv` starts the 10-foot TV interface, which suits a gamepad or remote.
Use `--fullscreen` instead for the desktop interface, full screen, or neither to open in a window.

The player remembers the server URL and login in its own config, so the first launch asks for them once.

== Jellyfin Media Player

Jellyfin Desktop replaces the older https://github.com/jellyfin/jellyfin-media-player[Jellyfin Media Player].
If you still use that, its binary is `jellyfinmediaplayer` (`jellyfin-media-player` on some distributions) and its Flathub id is `com.github.iwalton3.jellyfin-media-player`:

[source,yaml]
----
    command: [jellyfinmediaplayer]
----

== Open the web UI instead

If you would rather use the server's browser client (for example there is no desktop player on the box):

[source,yaml]
----
  - title: Jellyfin
    subtitle: Media server
    command: [firefox, --kiosk, https://jellyfin.example.com]
    restoreOnExit: false
----

Use your real server URL.
`restoreOnExit: false` is the same idea as xref:examples/youtube.adoc[YouTube]: an already running Firefox may take the URL and exit.

== Notes

* The icon is looked up as `Jellyfin`.
* The desktop player stays running until you quit it, so leave `restoreOnExit` at the default.
* *Switch to it* finds a Flatpak's window by class: add `windowClass` with the value `xprop WM_CLASS` shows for the player window. See xref:config.adoc[].
* Output is appended to `~/.cache/biscuittin/jellyfin.log`.
